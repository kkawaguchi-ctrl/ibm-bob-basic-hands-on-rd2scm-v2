よくある質問

IBM Bob に関するよくある質問と回答をまとめています。

Bob とは何ですか？

Bob はAIを活用したコーディングアシスタントです。コードの作成、リファクタリング、さまざまなタスクの実行をサポートします。カスタムモードや指示を追加することで機能を拡張できます。

Bob はどのように機能しますか？

Bob は大規模言語モデル（LLM）を使用してリクエストを理解し、アクションに変換します。以下のことができます。

  • プロジェクト内のファイルの読み書き
  • ターミナルでのコマンド実行
  • インターネットの閲覧（有効化時）
  • Model Context Protocol（MCP）による外部ツールの利用

チャットインターフェースを通じて指示を出し、Bobが提案するアクションを確認・承認しながら作業を進めます。

Bob は何ができますか？

Bob はさまざまなコーディングタスクをサポートします。

  • 自然言語の説明からのコード生成
  • 既存コードのリファクタリング
  • バグ修正
  • ドキュメントの作成
  • コードの説明
  • コードベースに関する質問への回答
  • 繰り返し作業の自動化
  • 新しいファイルやプロジェクトの作成
Bob で処理できないデータの種類はありますか？

以下のデータは Bob で処理しないでください。

  • SPI（特別な個人情報）
  • 個人の健康情報（PHI）
  • 輸出規制対象データ（ITAR、APP など）
  • 規制対象の財務データ（銀行口座番号、カード番号（PAN）、非公開の財務データ）
Bob を利用するリスクはありますか？

Bob は強力なツールです。責任を持って利用することが重要です。

  • Bob はミスをすることがあります。 提案された変更は必ず注意深く確認してから承認してください。
  • Bob はコマンドを実行できます。 特に自動承認を有効にしている場合は、コマンドの実行を依頼する際に十分注意してください。
新しいタスクを開始するにはどうすればよいですか？

Bobパネルを開き、チャットボックスにタスクを入力します。Bobに何をしてほしいかを明確かつ具体的に伝えてください。

モードを切り替えるにはどうすればよいですか？

チャット入力エリアのドロップダウンメニューから別のモードを選択するか、/ コマンドを使用して特定のモードに切り替えます。

ツールとは何ですか？どのように使いますか？

ツールはBobがシステムと連携する手段です。Bobはタスクを完了するために適切なツールを自動的に選択・使用します。ツールを直接呼び出す必要はありません。各ツールの使用時には承認または拒否の確認が表示されます。

コンテキストメンションとは何ですか？

コンテキストメンションは、ファイル、フォルダー、問題など、プロジェクトに関する特定の情報をBobに提供する方法です。@ 記号に続けて参照したいアイテムを記述します（例：@/src/file.ts、@problems）。

Bob はターミナルでコマンドを実行できますか？

はい、Bobはコマンドを実行できます。コマンドの自動承認を有効にしていない限り、各コマンドの実行前に承認の確認が表示されます。コマンドの自動承認は十分に注意して行ってください。

Bob にフィードバックを送るにはどうすればよいですか？

Bobが提案するアクションを承認または拒否することでフィードバックを提供できます。フィードバックフィールドを使用して追加のコメントを入力することもできます。

Bob の動作をカスタマイズできますか？

はい、Bobはいくつかの方法でカスタマイズできます。

  • カスタム指示: すべてのモードまたは特定のモードに適用される一般的な指示を提供します。
  • カスタムモード: カスタマイズされたプロンプトとツール権限を持つ独自のモードを作成します。
  • Bobルール: プロジェクトルートの .bob/rules/ フォルダーにMarkdownのルールファイルを作成して追加のガイドラインを提供します。
  • 設定: 自動承認、差分編集などのさまざまな設定を調整します。
Bob には自動承認の設定がありますか？

はい、Bobには有効にするとアクションを自動的に承認するいくつかの設定があります。

MCP（Model Context Protocol）とは何ですか？

MCPはBobが外部サーバーと通信するためのプロトコルです。カスタムツールやリソースを追加することで、Bobの機能を拡張できます。

独自の MCP サーバーを作成できますか？

はい、独自のMCPサーバーを作成してBobにカスタム機能を追加できます。

Bob が応答しません。どうすればよいですか？
  • APIキーが正しく、期限切れになっていないか確認してください。
  • インターネット接続を確認してください。
  • VS Code を再起動してみてください。
Bob が意図しない変更を加えました。元に戻すにはどうすればよいですか？

BobはVS Codeの組み込みファイル編集機能を使用しています。標準の「元に戻す」コマンド（Ctrl / Cmd + Z）で変更を元に戻すことができます。チェックポイントを使用してファイルへの変更を元に戻すこともできます。
