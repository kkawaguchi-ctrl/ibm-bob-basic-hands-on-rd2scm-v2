## 実装手順

既存の `faq.html` を以下の順序で修正する。

1. **CSS変数の導入とテーマカラーの統一**
   - `<style>` 先頭の `:root` に CSS変数を定義する
     - `--accent: #0f62fe`（IBM Blue = bob.svg のメインカラー）
     - ライトテーマ: `--bg: #ffffff`, `--surface: #f4f4f4`, `--text: #21272a`, `--border: #e0e0e0` など
     - ダークテーマ: `body.dark` セレクタで各変数を上書きする（`--bg: #161616`, `--surface: #262626`, `--text: #f4f4f4` など）
   - 既存のカラー指定を CSS変数参照に置き換える

2. **ヘッダーの構造変更（Bob画像・ダークテーマボタン）**
   - `<header>` 内に左右2カラムのレイアウトを追加する（flex）
   - 左側: `<a href="https://www.ibm.com/products/bob">` で `<img src="bob.svg">` を囲む（高さ 44px 程度）
   - 右側: ダークテーマ切り替えボタン `<button id="theme-toggle">` を配置する（初期アイコン 🌙）

3. **ダークテーマ JavaScript の追加**
   - `<script>` に `theme-toggle` ボタンのクリックハンドラを追加する
   - クリック時に `document.body.classList.toggle('dark')` を実行する
   - ボタンアイコンをライト時「🌙」、ダーク時「☀️」に切り替える

4. **動作確認（手動）**
   - ブラウザでローカルファイルとして開き、全追加機能を確認する

## GUI実装

* **対象コンポーネント:**
  - ヘッダー左: Bob画像（`<img src="bob.svg">`）を `<a>` タグで囲んだリンク
  - ヘッダー右: ダークテーマ切り替えボタン（`<button id="theme-toggle">`）
  - 検索ボックス: キーワード入力 `<input type="text">`
  - タブナビゲーション: `<button>` × 4（カテゴリ切り替え）
  - アコーディオンアイテム: `<div>` + JS で実装
  - 検索結果なしメッセージ: `<p>` 要素（非表示/表示切り替え）

* **スタイル（ライトテーマ）:**
  - ベースカラー: 白（`#ffffff`）、テキスト: ダークグレー（`#21272a`）
  - アクセントカラー: `#0f62fe`（IBM Blue）
  - フォント: システムフォント（`system-ui, sans-serif`）
  - タブアクティブ: ボーダーボトムまたは背景色でハイライト

* **スタイル（ダークテーマ `body.dark`）:**
  - 背景: `#161616`、サーフェス: `#262626`
  - テキスト: `#f4f4f4`
  - アクセントカラー: `#0f62fe`（同色維持）
  - ボーダー: `#393939`

* **状態管理:** 純粋なJavaScriptでDOM操作（外部状態管理ライブラリなし）

* **画面遷移:** シングルページ内の表示切り替えのみ（ページ遷移なし）

* **レスポンシブ対応:**
  - コンテナ: `max-width: 800px; margin: 0 auto;`
  - タブ: 小画面では横スクロールまたは折り返し
  - アコーディオン: 幅100%で可変
