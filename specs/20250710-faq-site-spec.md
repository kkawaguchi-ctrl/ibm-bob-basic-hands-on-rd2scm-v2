## 背景・目的

プロジェクトルートに存在する `qa.md` に英語のFAQコンテンツが記載されている。
このFAQコンテンツを日本語に翻訳し、バックエンドを必要としない単一HTMLファイルのFAQサイトとして提供する。

## 現在の挙動

`qa.md` にFAQコンテンツが英語テキストとして存在するが、HTMLサイトは存在しない。

## 期待する挙動

`faq.html` を開くと、日本語のFAQサイトが表示される。
カテゴリタブ・アコーディオン・キーワード検索が動作する。

## 対象範囲・対象外

### 対象範囲

* `faq.html` の新規作成（HTML / CSS / JavaScript を1ファイルに統合）
* `faq.html` への追加改修（Bob画像挿入・リンク・テーマカラー変更・ダークテーマ）

### 対象外

* バックエンド処理
* `bob.svg` の変更
* 外部ライブラリ・CDNの利用

## 利用者・影響システム

* 利用者: ブラウザでアクセスするエンドユーザー
* 影響システム: なし（静的HTMLのみ）

## 主な仕様

1. **コンテンツ:** `qa.md` の全FAQエントリを日本語に翻訳して掲載する
2. **カテゴリタブ:** 以下4カテゴリをタブで切り替える
   - 全般（General）
   - 使い方（Usage）
   - 高度な機能（Advanced Features）
   - トラブルシューティング（Troubleshooting）
3. **アコーディオン:** 質問クリックで回答が開閉する
4. **キーワード検索:** 入力したキーワードでリアルタイムにQ&Aをフィルタリングする（質問・回答両方を対象）
   - 検索中はカテゴリタブの絞り込みを解除し、全カテゴリを対象にする
   - 検索ボックスを空にするとタブ表示に戻る
5. **Bob画像:** ヘッダー左上に `bob.svg` を表示する
   - 画像をクリックすると `https://www.ibm.com/products/bob` へ同タブで遷移する
6. **テーマカラー:** `bob.svg` のメインカラー `#0f62fe`（IBM Blue）を基準色としてサイト全体のアクセントカラーを統一する
7. **ダークテーマ:** ヘッダー右端にダークテーマ切り替えボタンを設置する
   - ボタンクリックでライト/ダーク切り替えを行う
   - ダーク時はページ全体の背景・テキスト・コンポーネントの配色を反転する
   - CSS変数と `<body>` クラスの切り替えで実装する

## 制約・非機能要件

* バックエンドなし（純粋なHTML / CSS / JavaScript）
* 外部ライブラリ・CDN不使用
* レスポンシブデザイン対応（デスクトップ・スマートフォン）
* 単一HTMLファイル（`faq.html`）

## UI・画面仕様

### 対象画面

FAQサイト（単一ページ）

### 画面構成・表示項目

| エリア | 内容 |
|---|---|
| ヘッダー左 | Bob画像（`bob.svg`）＋リンク（`https://www.ibm.com/products/bob`）、サイトタイトル |
| ヘッダー右 | ダークテーマ切り替えボタン |
| 検索エリア | キーワード入力ボックス |
| タブエリア | カテゴリタブ（全般 / 使い方 / 高度な機能 / トラブルシューティング） |
| FAQリスト | 各カテゴリのQ&Aアコーディオン一覧 |

### 操作・画面遷移

* カテゴリタブクリック → 対応カテゴリのFAQリストを表示
* 質問クリック → 回答の開閉（トグル）
* キーワード入力 → 全カテゴリ対象でリアルタイムフィルタリング
* 検索ボックスクリア → タブ表示に戻る

### 表示状態

| 状態 | 内容 |
|---|---|
| 初期表示 | 「全般」タブがアクティブ、回答はすべて折り畳み状態 |
| タブ切り替え | 選択タブのFAQのみ表示、回答は折り畳み状態にリセット |
| 検索中 | タブ非表示またはすべてのタブを横断したフィルタリング結果を表示 |
| 検索結果なし | 「該当するFAQが見つかりませんでした」と表示 |

### 入力・バリデーション

* キーワード検索: 全角・半角問わず入力可能。空欄で全件表示

### デザイン要件

* シンプルでモダン（白背景・清潔感）
* アクセントカラーは `bob.svg` のメインカラー `#0f62fe`（IBM Blue）
* ダークテーマはダーク背景（`#161616`程度）、ライトテキスト、アクセントカラーは同色維持
* ヘッダー左上にBob画像（高さ 40〜48px 程度）
* ダークテーマボタンはヘッダー右端に配置（アイコンまたはテキスト）
* レスポンシブ対応（max-width: 800px 程度）
* カーソルホバー時に視覚フィードバック
